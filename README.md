# Mortgage AI — локальный Telegram-бот

Первая версия бота для ипотечной команды: отвечает на `/start`, а по команде
`/start_deal` создаёт ID сделки и локальную папку для неё. Документы и
фотографии, присланные после этого в тот же чат, сохраняются локально.

## Что потребуется

- macOS и Python 3.10+;
- токен созданного бота из BotFather;
- для работы в групповом чате: добавьте туда бота и в BotFather отключите
  Privacy Mode (`/setprivacy` → `Disable`).

Если macOS сообщает, что отсутствуют инструменты разработчика, установите их:

```bash
xcode-select --install
```

## Запуск

В Терминале перейдите в папку проекта и выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Откройте `.env` и вставьте токен в одну строку без кавычек:

```text
BOT_TOKEN=ваш_токен_из_BotFather
```

Запустите бота:

```bash
python bot.py
```

В Telegram отправьте боту или в тестовой группе `/start`, затем `/start_deal`.
Остановить программу можно сочетанием `Ctrl+C` в Терминале.

После `/start_deal` в папке проекта появится такая структура:

```text
Deals/
└── ДД.ММ.ГГГГ ЧЧ-ММ-СС/
    └── Documents/
```

Бот запоминает связь чата и сделки в локальном файле `data/chat_deals.json`.
Он нужен только для работы на этом Mac и не содержит токенов. Одна новая
команда `/start_deal` в чате назначает этому чату новую сделку.

Папку сделки можно вручную переименовать в Finder, например в `Иванов Иван`.
Бот продолжит находить её и сохранять документы в `Documents`.

## Приём документов

После создания сделки отправьте в тот же Telegram-чат файл как **документ**
или отправьте фотографию. Бот подтвердит сохранение, а файл окажется в
`Deals/<ID сделки>/Documents`.

Для приёма обычных файлов в групповом чате в BotFather должно быть отключено
Privacy Mode: `/setprivacy` → выберите бота → `Disable`.

## Фильтр документов команды

Документы и фотографии от указанных участников можно не сохранять. В `.env`
добавьте строку (без символа `@`):

```text
EXCLUDED_USERNAMES=Anastasia_ipoteka,andrey_ipoteka
```

Файлы от этих двух Telegram-юзернеймов будут пропущены, а файлы от остальных
участников чата сохранятся как обычно. Юзернейм можно изменить в Telegram,
поэтому для более строгой настройки бот также отвечает на `/my_id` и показывает
неизменяемый числовой Telegram ID отправителя.

## Отзывы клиентов

В личном чате бот предлагает всем, кроме руководителя и менеджера, оставить
оценку от 1 до 5 и комментарий. Отзыв пересылается руководителю в личный чат
с ботом. Добавьте в локальный `.env` его числовой Telegram ID:

```text
MANAGER_USER_ID=1680647231
```

Перед проверкой руководитель должен хотя бы раз открыть личный чат с ботом и
отправить ему `/start`, иначе Telegram не позволит боту написать ему первым.

## Распознавание паспортов

Бот локально проверяет присланные изображения и до двух первых страниц PDF.
Если файл распознан как российский паспорт, он переименовывается в
`Паспорт.pdf`. Бот намеренно не извлекает и не использует ФИО на этом этапе.
Документы других типов остаются с исходным именем. Для работы нужны Tesseract
OCR и русский языковой пакет (`rus`).
Перед распознаванием бот пытается автоматически исправить поворот страницы.
Для более устойчивого чтения он использует несколько режимов OCR и проверяет
как заголовок паспорта, так и характерную структуру страницы с данными.

Если клиент отправляет несколько страниц паспорта одним Telegram-альбомом,
бот проверяет их вместе и сохраняет как `Паспорт 1.jpg`, `Паспорт 2.jpg` и
так далее. Альбом вмещает до 10 изображений, поэтому подходит для 9–10
разворотов паспорта. На текущем этапе страницы нужно отправлять именно
фотоальбомом. Для подтверждения достаточно одной читаемой страницы с
характерными признаками паспорта; пустые или нечитаемые страницы не отменяют
обработку всего альбома.

## Распознавание СНИЛС

Бот также распознаёт СНИЛС: современный документ с надписью «СНИЛС» и старое
страховое свидетельство обязательного пенсионного страхования. Распознанный
файл получает имя `СНИЛС.pdf` или `СНИЛС.jpg`. Фотографии с сильным наклоном,
бликами или закрытым текстом могут не распознаться и останутся с исходным
именем для ручной проверки.

## Неопознанные документы

Бот даёт новое имя только документам, которые распознаёт уверенно. Неизвестные
или плохо читаемые файлы сохраняются с исходным именем. Для каждого файла OCR
имеет ограничение по времени, чтобы один сложный документ не задерживал
обработку остальных.

## Другие распознаваемые документы

Бот также распознаёт и именует: `Справка 2-НДФЛ`, `Свидетельство о заключении
брака`, `Свидетельство о расторжении брака` и `Свидетельство о рождении`.

## Безопасность

`.env` уже исключён из Git. Никогда не отправляйте токен в чат и не добавляйте
его в код. В будущем также не будут попадать в Git документы клиентов.
